AepThumb shows the real rendered content of After Effects projects as
thumbnails in Windows Explorer.

How it works, in short
----------------------
An .aep file contains no picture of any kind - only the project structure.
Nothing but After Effects can turn it into an image. So AepThumb renders one
frame per project in the background, stores it in a per-user cache, and the
Explorer thumbnail handler then simply shows that cached frame instantly.

The first time a folder of projects is browsed, tiles appear as placeholder
cards and are replaced by real frames a few seconds later, as they finish
rendering. After that they are instant and stay cached until the project is
edited.

Requirements
------------
- Windows 10 or 11, 64-bit
- Adobe After Effects installed
- In After Effects: Edit > Preferences > Scripting and Expressions >
  "Allow Scripts to Write Files and Access Network" must be enabled.
  Rendering cannot work without it.

Good to know
------------
- Rendering pauses while After Effects is open, so your own session is never
  disturbed. It resumes afterwards.
- The first render of each project takes a few seconds. After Effects is
  started once for a batch, not once per file.
- Setup takes over .aep thumbnails machine-wide. If another program already
  handled them, that setting is saved and restored when you uninstall.
